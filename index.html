How was this score calculated? (the maths, in the open)

Every warning sign has a fixed number of points. The score is simply the sum of the points for the signs we found, capped at 100. Nothing is hidden or weighted by a mystery algorithm.

Bands: 0–24 Low Risk 25–59 Suspicious 60–100 High Risk

About this tool

The Phishing Email Analyser is a learning aid for spotting phishing and social-engineering patterns. It uses transparent, rule-based checks — no artificial intelligence, no external services, no data collection.

Stay safe

Treat any unexpected request for passwords, codes, payments or bank changes as suspicious. If in doubt, verify the sender using an official website, app or phone number you already trust — never the details in the email itself.

Privacy

This page makes no network requests for analysis and stores nothing. It works fully offline, which is why it can be hosted as a free static site.
